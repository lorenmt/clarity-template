End-to-End Multi-Task Learning with Attention

Shikun Liu 1, Edward Johns 1, Andrew J. Davison 1

1 Imperial College London

We propose a novel multi-task learning architecture that uses attention modules to learn task-specific feature-level attention. Our approach allows different tasks to share a common feature backbone while dynamically adapting features for each individual task.

Introduction

Multi-task learning aims to improve generalisation by leveraging domain-specific information contained in the training signals of related tasks. Rather than training separate models for each task, a shared representation can be learned that captures common structure across tasks.

In the context of deep learning, multi-task architectures broadly fall into two categories: hard parameter sharing and soft parameter sharing. Hard parameter sharing involves sharing the hidden layers between all tasks while keeping separate task-specific output heads.

Recent work has shown that naively sharing representations can sometimes hurt performance when tasks compete for capacity in the shared network. This phenomenon, known as negative transfer, motivates the need for more sophisticated sharing mechanisms.

Related Work

Multi-Task Architectures

Early multi-task learning methods focused on linear models. With the advent of deep learning, convolutional networks became the dominant architecture for dense prediction tasks. Cross-stitch networks introduced learnable linear combinations of features from task-specific networks.

Attention Mechanisms

Attention mechanisms were originally proposed for machine translation and have since been adopted across many domains. The Transformer architecture demonstrated that self-attention alone could replace recurrence entirely. Squeeze-and-Excitation networks introduced channel-wise attention for image classification.

Method

Our method introduces a Multi-Task Attention Network (MTAN) that consists of a shared feature backbone $\mathcal{F}$ and $K$ task-specific attention modules. Each attention module learns a soft attention mask over the shared features:

$$ \mathbf{g}_{k,l} = a_{k,l}(\mathbf{f}_l) \odot \mathbf{f}_l $$

This formulation is related to the gating mechanisms in highway networks and the feature recalibration in SE-Nets, but applied specifically to the multi-task setting.

Experiments

We evaluate MTAN on NYUv2 and CityScapes. For NYUv2, we perform semantic segmentation, depth estimation, and surface normal prediction simultaneously.

Conclusion

We have presented MTAN, a multi-task learning architecture that uses task-specific attention modules to dynamically adapt shared features for each task. Experiments demonstrate consistent improvements over strong baselines.
